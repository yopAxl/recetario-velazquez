# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

React + Vite (existing scaffold). Static/hardcoded data — no database or backend.

## Users

Primary: a student or developer submitting a course assignment. Evaluators will judge functionality, code quality, and UI/UX craft. Secondary: anyone who might actually cook from the app (phone or desktop).

## Product Purpose

A static recipe book web app showcasing two Mexican recipes — rooted in Nayarit regional cuisine, with "enchilada suiza" as a named reference dish. The app demonstrates competence in React and good UX/UI design. Success means: the two recipes are clear and usable, the interface is polished enough to earn high marks, and the code is clean.

## Positioning

A curated, personal recipe reference — not crowdsourced or algorithmic. The Velázquez name signals authorship and cultural specificity (Nayarit, Mexico). Its differentiator over a generic recipe site is its focused, crafted, single-author character.

## Operating Context

- Viewed in a browser (desktop and mobile); likely evaluated on a laptop.
- The user reads and follows a recipe while cooking, so readability and step clarity matter.
- Two recipes hardcoded as static data in React components or a JS data file.
- No user accounts, no database, no API.

## Capabilities and Constraints

- Exactly two recipes (content TBD; one may be enchilada suiza or a Nayarit regional dish).
- All content is hardcoded — no CMS, no backend, no fetch.
- React + Vite stack.
- No authentication or user-generated content.
- Recipe content (photos, exact text) has not yet been authored — future work must not fabricate testimonials, sourcing claims, or nutritional facts.

## Brand Commitments

- Name: **Recetario Velázquez** (Velázquez's Recipe Book).
- Cultural identity: Mexican cuisine, Nayarit region emphasis.
- No formal logo, color palette, or typography spec confirmed yet.

## Evidence on Hand

- No real photography or authored recipe text on disk yet.
- No testimonials, reviews, or external press.

## Product Principles

1. **Clarity over complexity.** Every recipe step and ingredient must be immediately readable — especially on mobile, while someone has their hands busy.
2. **Cultural specificity earns credibility.** The Nayarit identity is a strength; honor it through content and visual choices, not just the name.
3. **Craft signals competence.** Since the primary context is an academic evaluation, every design decision should be deliberate and demonstrable.
4. **Static is a feature.** No database dependency means instant load and zero runtime failures — lean into it.
5. **Two recipes done right beats ten done carelessly.** Depth over breadth.
